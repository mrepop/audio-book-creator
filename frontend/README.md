# Audio Book Creator - Frontend

React + TypeScript web interface for the Audio Book Creator.

## Planned Features

- Book upload and chapter browser
- Dramatis personae (character sheet) editor with voice preview
- Chapter-by-chapter generation view with progress tracking
- Sentence-level editor for fine-tuning emphasis, voice, and text
- Hands-free mode toggle for fully automated generation
- Audio player with chapter navigation
- Voice profile management (create, edit, assign to characters)
- A/B comparison for voice previews

## Setup (Coming Soon)

```bash
npm install
npm run dev
```

The frontend will be served at `http://localhost:5173` during development
and built to `dist/` for production (served by the FastAPI backend at `/app`).
